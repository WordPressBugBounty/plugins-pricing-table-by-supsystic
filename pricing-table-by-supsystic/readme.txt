== Description ==

**Pricing Table by Supsystic** is a WordPress pricing table plugin for pricing plans and feature comparison tables. Pick a template, type your prices and features right inside the table, highlight the plan you want to sell and publish it with a shortcode. No code required.

Unlimited tables, columns and rows are free.

**Try it in your browser:** [open a live demo in WordPress Playground](https://playground.wordpress.net/?plugin=pricing-table-by-supsystic) – no install, no account.

= What you can build =

* Pricing plans for SaaS, hosting, apps, memberships and subscriptions
* Feature comparison tables with check and cross icons
* Service packages for agencies, freelancers and consultants
* Product comparison tables with images and specifications

= Visual table builder =

* Edit text right inside the table and see the result as you type
* Add, clone, move and remove columns and rows
* Highlight a column and add a hover animation so the best plan stands out
* Column badges such as "Most popular", "Best value" or "Sale" from a ready badge library
* Icons from a built-in icon library, images, videos and buttons in any cell
* Colours, fonts, header style and borders for every table, plus custom CSS

= Turn visitors into buyers =

* Buttons link to any checkout: a PayPal or Stripe payment link, a WooCommerce product, your cart or a contact form
* Payment icons for PayPal, Stripe and cards to build trust next to the price
* Links can open in a new window and carry a nofollow attribute

= Scheduled columns for sales =

= Responsive on every screen =

Tables adapt to desktops, tablets and phones. Responsive mode is on by default, and you can set a minimum column width or switch it off for fixed layouts.

== Installation ==

1. In your dashboard go to Plugins → Add New Plugin and search for "Pricing Table by Supsystic".
2. Click Install Now, then Activate.
3. Open the Pricing Table menu and create a new table from a template.
4. Type your plans, prices and features, then save.
5. Copy the table shortcode and paste it into any page or post.

== Frequently Asked Questions ==

= Is the free version limited in tables, columns or rows? =

No. You can create unlimited tables with unlimited columns and rows. The free plugin never expires.

= How do I add a pricing table to a page? =

Each table has its own shortcode, for example `[supsystic-price-table id=1]`. Paste it into any post, page or widget area. For theme templates, use the PHP code shown next to the shortcode.

= Can I highlight the plan I want to sell? =

Yes. Highlight or enlarge a column, add a hover animation and put a badge such as "Most popular" or "Best value" on it.

= Can I add a monthly/annual price switch? =

Yes, with Pro. The switch toggle shows different prices in the same table, for example monthly and annual billing.

= Can I show a special offer only for a few days? =

Yes. Scheduled columns appear and disappear between the dates you set, which is ideal for Black Friday, launches and seasonal sales.

= Can I connect the buttons to PayPal, Stripe or WooCommerce? =

Yes. A button can link to any URL: a PayPal or Stripe payment link, a WooCommerce product or cart page, or a contact form.

= Can I add images, videos and icons to the table? =

Yes. Any cell can hold an image, a video, an icon from the built-in library or a button.

= Can I create a comparison table instead of pricing plans? =

Yes. Use rows for features and columns for plans or products, with check and cross icons, images and specifications.

= Are the tables responsive? =

Yes. Tables adapt to every screen size. You can also set a minimum column width or turn responsive mode off.

= Can I set a custom width for a column? =

Yes. Turn off responsive mode, open the column editor, choose Attribute and enter a style such as `width: 25%;` for each column. The widths of all columns should add up to 100%.

= Can I move tables to another site? =

Yes. Export a table and import it on another WordPress site.

= Does it work with my theme and page builder? =

The plugin works with modern WordPress themes. In page builders, use the shortcode.

= How can I report a security issue? =

Please report security issues through the [Patchstack Vulnerability Disclosure Program](https://patchstack.com/database/vdp/9e5fb554-f2d8-4df3-9dc0-bbac3d7a0229). The Patchstack team validates and triages each report and notifies us.
